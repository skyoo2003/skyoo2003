# Hi, I'm Sung-Kyu Yoo

I'm a backend engineer building tools in Go. My interests include
distributed systems, storage, and local cloud development.

## Projects

- **[devcloud](https://github.com/skyoo2003/devcloud)**: A local CSP API emulator for development and testing, with Smithy-driven code generation.
- **[acor](https://github.com/skyoo2003/acor)**: A Go library for Aho-Corasick multi-pattern matching, with a shared pattern dictionary stored in Redis or Valkey.
- **[kvs](https://github.com/skyoo2003/kvs)**: A key-value store that runs as a server or embeds in Go applications. Supports HTTP, gRPC, and RESP, with optional Raft clustering.
